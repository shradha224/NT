feat: full system overhaul (plug & play db, sync, ui, qr)

Summary:
We have fully transformed this project into an easy-to-use, offline-first IoT application that runs instantly on any device! There is no manual database setup anymore, cloud syncing only happens twice a day to save rural bandwidth (with a cool manual sync button), the clunky login/register forms are now giant simple buttons, and you can generate and scan QR codes straight from your browser camera without needing external apps.

Technical Documentation:
1. Zero-Config Architecture (mongodb-memory-server)
Replaced the hard dependency on an external MongoDB instance with `mongodb-memory-server`. Added a waker utility (`backend/src/utils/mongoWaker.js`) that boots the embedded database automatically during `npm start`.

2. Offline-First Sync Optimization (SyncManager)
Adjusted the aggressive `SyncManager` background polling cycle from 1 minute to 12 hours (43,200,000ms) to conserve bandwidth on low-connectivity edge nodes. Added a new secure endpoint (`POST /api/sync/manual`) and a frontend "Sync Hub" card in the Profile Dashboard to allow manual two-way synchronization on-demand.

3. "Farmer-First" UI/UX Overhaul
- Converted `RegisterPage.jsx` into a state-driven 4-step wizard with prominent, touch-friendly UI components.
- Converted `LoginPage.jsx` to a "Method-First" view where users select their auth method (Fingerprint, Phone, Email) before seeing any forms.
- Replaced the confusing Google Auth implementation to adhere to the strict plug-and-play requirement.

4. Live Browser QR Code Integration
- Integrated `qrcode.react` in `BatchCreated.jsx` to dynamically generate SVG QR codes bound to the specific `batchId`, complete with native browser download functionality.
- Integrated `html5-qrcode` in both Aggregator and Farmer scanning routes. Leverages the HTML5 MediaDevices API to access device cameras (requires HTTPS/localhost), decode QR contents, and route the user to the corresponding Quality Passport dynamically.
